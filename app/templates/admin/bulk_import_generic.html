    CSV Format Guidelines

    • First row must contain column headers (exactly as shown in export)
    • Use comma (,) as the delimiter between columns
    • Enclose text containing commas in double quotes
    • Use "Yes"/"No" or "True"/"False" for boolean fields
    • Leave cells empty for optional fields (don't use "NULL" or "N/A")
    • Ensure numbers are formatted without currency symbols or thousands separators
    • Part numbers and codes must match exactly (case-sensitive)
