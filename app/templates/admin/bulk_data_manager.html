    Tips & Best Practices

    • Always export current data before importing to have a backup
    • Test imports with a small CSV file first (2-3 rows) to verify format
    • Ensure CSV files are UTF-8 encoded to avoid character encoding issues
    • Part numbers and SKUs are case-sensitive and must match exactly
    • For related data (e.g., pumps with series), import series first
    • Watch for error messages after import - they indicate which rows failed
