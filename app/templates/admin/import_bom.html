    How to Import BOM Data
    1. Download the sample template to see the correct format
    2. Prepare your data using the same column structure
    3. Ensure pumps exist in the system (create them first if needed)
    4. Upload your CSV file using the form below

    Note: The import will automatically create missing components if "Create Missing Components" is checked.

    CSV Format:
    Pump Part Number, Pump Name, Inertia Base Part Number,
Inertia Base Dimensions, Spring Part Number, Spring Quantity, Notes

    Note: BOM includes default inertia base and springs. During configuration, user can swap inertia base for crossbar if desired.

    Important Notes
    • Pumps must exist before importing BOM data
    • BOM includes: Inertia Base (default) + Seismic Springs (with quantity)
    • Part numbers must match exactly for existing components
    • Dimensions format: length x width x depth (e.g., 1200 x 800 x 200)
    • Spring quantity defaults to 1 if not specified
    • Configuration options during pump selection:
      • Swap Crossbar for Inertia Base (user choice)
      • Motor Protection: Yes/No
      • Drip Tray: Yes/No (max 1 per pump)
    • Overwrite mode will delete existing BOM entries for pumps in the file
    • Create missing components will auto-create components that don't exist
