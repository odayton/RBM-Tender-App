    Manage Pump BOM (Bill of Materials)

    Link Component to Pump
    How to Use BOM Management

    The Bill of Materials (BOM) links pumps to their required components (inertia bases, springs, mounts, etc.).

    Workflow:

    1. First, find the component ID from the component management pages below
    2. Click "Link Component to Pump" to create a new BOM entry
    3. Select the pump, component type, and enter the component ID
    4. Set the quantity and whether it's optional
