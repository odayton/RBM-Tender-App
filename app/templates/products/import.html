CSV Format Guide
Required Columns:
  • sku - Unique product identifier
  • name - Product name
  • unit_price - Price in dollars
  • category - Product category
Optional Columns:
  • description - Product description
  • brand - Brand name
  • model_number - Model number
  • weight_kg - Weight in kilograms
  • dimensions - Dimensions (LxWxH cm)
  • stock_quantity - Current stock
  • reorder_level - Reorder threshold
  • lead_time_days - Lead time in days
  • is_active - Active status (true/false)
  • notes - Internal notes

Import Tips
Best Practices
  • Use unique SKUs for each product
  • Ensure prices are positive numbers
  • Use standard categories for consistency
  • Test with a small file first
  • Backup your data before large imports
Important Notes
  • SKU must be unique across all products
  • Prices must be positive values
  • Stock quantities cannot be negative
  • Large files may take time to process
