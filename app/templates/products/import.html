Import Guide
Important Notes
  • Item No is the primary identifier
  • Description is the main product name
  • Category is required for all products
  • SubCategory helps with organization
Required Fields:
  • Item No (unique identifier)
  • Description (product name)
  • Category
  • Pack (default: 1)
  • Carton Qty (default: 1)
  • is_active (true/false)
Optional Fields:
  • SubCategory
  • Series
  • List price
  • Disc Code
  • Note
  • weight_kg
  • dimensions
  • lead_time_days
Tips
  • Use quotes for text containing commas
  • Leave empty cells for optional fields
  • Use true/false for is_active field
  • Save file as UTF-8 encoding
Migration from Old Format

The system will automatically set defaults for any missing fields.
